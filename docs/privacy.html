Gretel collects nothing.

Gretel is the Android app published under the package name com.abeant.gretel. This policy covers that app and this website. It applies to every distribution channel, including GitHub Releases, F-Droid, and Google Play.

Data we collect

None. Gretel has no server, no account system, and no way to send anything anywhere.

  • No personal or sensitive user data is collected, transmitted, or shared.
  • No accounts, analytics, advertising, crash reporters, or telemetry.
  • No Google Play Services, Firebase, or Crashlytics.
  • No INTERNET permission, so the app cannot make network calls even in principle.
  • No contacts, location, storage, microphone, camera, or SMS permissions.

Data stored on your device

Gretel saves a small number of settings in Android's private per-app preference storage. That data never leaves the device and is not readable by other apps.

  • The package name of the app you chose.
  • Whether you finished the introduction.
  • Your double-Home timing, theme, and the two reopen switches.
  • Markers for the last restart and the last Home press, so "open after a restart" can tell a restart from an ordinary Home press.

Android backup and cloud backup are disabled for Gretel (android:allowBackup="false"), so these settings are not copied off the device by the system either. Uninstalling Gretel deletes all of it.

Access to your installed apps

To let you pick an app, Gretel asks Android for the list of apps that publish a launcher entry, using a scoped manifest <queries> declaration. Gretel does not request the QUERY_ALL_PACKAGES permission and does not see your full app list. Nothing about your installed apps is recorded or transmitted.

Children

Gretel is not directed at children and collects no data from anyone, including children.

Third parties

Gretel contains no third-party SDKs. This website loads no fonts, scripts, trackers, or other third-party resources. It is hosted on GitHub Pages, and GitHub may log ordinary web server request data as described in the GitHub Privacy Statement.

Changes

Gretel is a local home app. If that ever changes, this policy changes first, and the change is visible in the public commit history at github.com/abeant/gretel.
