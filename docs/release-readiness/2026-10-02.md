## Repeatable verification script

These scripts currently require Bash 4+, GNU coreutils (including sha256sum),
and unzip; the download mode also requires gh. The stock macOS shell/toolset
is not sufficient without those prerequisites.

`scripts/verify-release.sh` verifies a release directory or downloads a tag
with `gh`: strict SHA256SUMS validation (exactly `gretel.apk` and
`gretel.aab`, no paths or extra entries), `sha256sum -c`, and zip integrity.
apksigner and aapt checks run when those tools exist and are reported as
skipped otherwise. `scripts/test-verify-release.sh` exercises it against the
fixtures in `scripts/fixtures/release-ok/` plus tampered cases; all cases
pass on this host, and the script reports 0 failures / 2 skipped against the
real v0.2.0 artifacts.
